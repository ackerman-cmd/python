# Результаты инструментальных проверок

Каталог содержит сохранённые результаты проверок проекта 14 октября 2026 года.
Интерпретация качества приведена в [REVIEW.md](../REVIEW.md), технических решений — в
[REPORT.md](../REPORT.md). Это снимки запусков, а не журналы постоянно работающего сервиса.

| Файл | Содержание | Для чего используется |
|---|---|---|
| [checks.json](checks.json) | Тесты, стиль, типы, установка wheel и итог ревью | Общая сводка с условиями запусков |
| [tests.xml](tests.xml) | JUnit XML с выполненными тестовыми случаями | Подтверждение 185 успешных случаев и результатов каждого теста |
| [coverage.json](coverage.json) | Покрытие операторов и ветвей по файлам | Расчёт 99,88%, 100,00% и суммарных 99,90% |
| [coverage-baseline.json](coverage-baseline.json) | Предыдущий снимок покрытия | Историческая точка сравнения; итоговые цифры берутся из coverage.json |
| [architecture.json](architecture.json) | Модули, внутренние импорты, границы ядра и отсутствие комментариев/docstring | Проверка структуры зависимостей |
| [demo.json](demo.json) | Импорт, дубликаты, конфликт, анализ и расширение | Сквозное поведение на учебном корпусе |
| [benchmark.json](benchmark.json) | Среда, объём, повторы и исходные времена | Ограниченное измерение приёма записей в памяти |

## Согласованность результатов

`checks.json` содержит сводные 185 тестов и 3,64 секунды зафиксированного запуска;
`tests.xml` содержит сами тестовые случаи. Для покрытия первичным источником служат
`totals` и данные отдельных файлов в `coverage.json`. Ветви включены, исходники заданы
настройкой `source = ["school_lab"]`.

В `demo.json` 12 принятых работ и 24 отчёта соответствуют двум основным анализаторам.
Отчёт расширения находится отдельно в `extension`, поэтому не входит в `report_count`.
Смешанный импорт и импорт из памяти выполняются в отдельных приложениях и не увеличивают
`repository_size` основного сценария. Списки accepted/duplicate описывают исходы записей.

`architecture.json` описывает статически найденные импорты. Проверка отсутствия циклов и
зависимостей ядра дополняет ревью, но не заменяет исполнение контрактов. Значения
`source_comments` и `source_docstrings` относятся к исходникам Python; документация проекта
находится в Markdown.

## Условия воспроизведения

Команды тестов, сборки, демонстрации и измерения приведены в [README](../../README.md).
Версии инструментов зафиксированы в `requirements-dev.lock`. Время тестов, UUID,
`created_at`, пути окружения и длительность benchmark при новом запуске могут отличаться.
Для демонстрации сравниваются исходы импорта, сохранность оригинала, хеши и смысловые
наблюдения, а не побайтовое равенство всего выходного JSON.

Основная проверка wheel на Python 3.13 выполнена в отдельном окружении с установленными
зависимостями. Дополнительный запуск на Python 3.12 использовал зависимости bundled runtime
через `system-site-packages`. Он подтверждает совместимость сценария с интерпретатором,
но не является второй проверкой чистой установки зависимостей. Пути удалённых временных
окружений в `checks.json` описывают место импорта во время проверки.

Benchmark включает создание источника в памяти, глубокое копирование, DTO, доменную
валидацию, SHA-256 и приём. Подготовка корпуса, сборка приложения, файловый ввод и запуск
анализаторов исключены. Результат относится к этому участку обработки и указанной среде.
